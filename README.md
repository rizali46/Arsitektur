# Muhammad RIzali Hafizhi | Developer Portfolio

A clean, responsive personal website built to showcase my recent projects, technical skills, and professional experience. 


## Tech Stack
* **Frontend:** React, TypeScript, Vite, Tailwind CSS, Motion, Lucide Icons
* **Backend & Tooling:** Node.js, Express, Dotenv
* **Deployment:** GitHub Pages (Automated via GitHub Actions)

## Local Setup

# Clone the repo
git clone https://github.com/rizali46/Arsitektur.git
cd Arsitektur

# Install dependencies
npm install

# Run local dev server
npm run dev
